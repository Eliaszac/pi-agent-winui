# Future work

Ideas and issues recorded for later consideration. This is not an implementation plan or approval to start work. Items retain the user's order; priorities are not assigned.

1. **Virtualize the conversation.** Improve performance for long conversation histories.
2. **Virtualize the sidebar list.** Improve performance with many projects and conversations.
3. **Investigate composer input delay.** The text box has a slight input delay in the production build.
4. **Command palette.** Add a command palette.
5. **Settings page.** Add a dedicated settings page.
6. **Docker extension and panel.** A GUI for managing container statuses. Manage Docker sources from the Extensions page and link containers to projects.
7. **Improve the Extensions page.** Separate extensions we consider essential, supported nice-to-have extensions, and our own extensions.
8. **Redesign side panels as tabs.** Give each side-panel view its own tab. Preserve multiple terminal tabs, support drag-and-drop reordering, and allow terminal tabs to be renamed.
