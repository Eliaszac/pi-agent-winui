# Application symbols

Retained official artwork, retrieved 2026-09-10:

- GitHub: official black/white Invertocat from https://brand.github.com/GitHub_Logos.zip. Used for the GitHub feature and integration, following https://brand.github.com/foundations/logo.
- VS Code: https://code.visualstudio.com/assets/branding/code-stable.png. Used for Open in VS Code actions under https://code.visualstudio.com/brand.
- Windsurf: https://exafunction.github.io/public/brand/windsurf-black-symbol.svg and https://exafunction.github.io/public/brand/windsurf-white-symbol.svg. Compact symbols under https://windsurf.com/brand.

The editor, folder and terminal-neutral light/dark SVGs are original project symbols, licensed under the root MIT license. They replace marks with unverified permission or unsuitable minimum sizing for compact menus, including JetBrains black-box logos. Product names still identify the installed application. The removed artwork is no longer bundled.

Retained third-party marks belong to their owners and identify the actual integration, without endorsement or affiliation. Do not recolor them. See [BRANDING.md](../../docs/BRANDING.md) for the policy review and release decisions.
