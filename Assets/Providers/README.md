# Provider brand marks

Bundled SVG brand marks from [Lobe Icons](https://github.com/lobehub/lobe-icons), package `@lobehub/icons-static-svg` version **1.95.0**. Source URLs follow `https://unpkg.com/@lobehub/icons-static-svg@1.95.0/icons/<brand>.svg`.

The collection reproduces provider brand artwork; it is not an official endorsement by those providers. See the included LICENSE. Brand names and trademarks remain their owners' property.

Vector geometry is unchanged. `currentColor` is resolved to `#1a1a1a` for light mode and `#f5f5f5` for dark mode because WinUI's SVG image source does not inherit XAML text color. The app loads only these local assets, with a native icon fallback for unknown providers.
