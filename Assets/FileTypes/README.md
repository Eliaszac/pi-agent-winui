# File icons

`material-*.svg` are unmodified icons from Material Icon Theme:
https://github.com/material-extensions/vscode-material-icon-theme/tree/main/icons
Downloaded 2026-09-11. Copyright Material Extensions; MIT license included in
`Material-LICENSE.txt`. Used for recognizable language/file-type symbols.

`NeutralFolder*.svg` are original application assets drawn on a 14px grid for
the explorer's 14 DIP icon size. Their neutral fill adapts to the active theme.

## Visual Studio legacy and fallback icons

These unmodified SVG assets are from Microsoft's Visual Studio 2026 Image Library,
downloaded from https://www.microsoft.com/en-us/download/details.aspx?id=35825.
Copyright Microsoft Corporation. These assets are NOT covered by any project source-code license.
The included VisualStudioImageLibrary-EULA.rtf governs their use and redistribution.
They are used solely as file/folder indicators in the application's development workspace.
The image library must not be redistributed as a standalone icon offering.
